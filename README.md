# metro 🚇

so basically this is my custom PCB project called **metro** — it's a mini LED map of the Sofia metro Line 2 because why not make hardware projects about public transport B)

## what's on the board?
- **ATtiny microcontroller** (the brain keeping everything together)
- A whole chain of LEDs mapped to actual stations (from Obelya all the way to Vitosha!)
- USB connector for power
- Some resistors and capacitors so it doesn't instantly fry
